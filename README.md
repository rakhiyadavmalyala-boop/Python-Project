# 🐍 Core Python Mini-Projects Collection

Welcome to my repository of foundational Python projects! This repo contains terminal-based games and tools built using **pure Python** (standard library only, zero external dependencies). 

These projects demonstrate core programming principles including object-oriented/modular design, dynamic control flow, game loop state management, and user input validation.

---

## 📂 Included Projects

### 1. 🃏 PyJACK (Terminal Blackjack Engine)
* **File:** `PYJACK.py`
* **Description:** A complete, interactive Blackjack game played in the command line against an automated dealer.
* **Key Features:**
  * Dynamic scoring logic that automatically converts Ace values (11 to 1) upon exceeding 21.
  * Automated dealer logic adhering to standard rules (hits on score < 17).
  * Clear game loop management with interactive turn decisions (Hit/Stand).

---

### 2. 🎲 Dice Rolling Game
* **File:** `dice_game.py`
* **Description:** A multi-round, turn-based dice game featuring score tracking and randomized outcomes.
* **Key Features:**
  * Uses Python's built-in `random` module for die simulation.
  * Implements robust input handling to manage user decisions across rounds.

---

### 3. ✂️ Rock, Paper, Scissors
* **File:** `rock_papper_scissor.py`
* **Description:** A classic command-line game allowing players to compete against the computer.
* **Key Features:**
  * Clean decision-tree conditional logic to evaluate win/loss/draw states efficiently.
  * Input sanitization to prevent crashes on invalid keystrokes.
